# Phase 4: `@clawforge/cli` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Checkbox (`- [ ]`) tracking.

**Goal:** Ship `@clawforge/cli` — the user-facing CLI (`npx clawforge ...`). Supports `init / add / list / info / update / remove / search / doctor / browse` against a clawforge-compatible registry. Shadcn-style: copy-paste default, optional `--track` for manageable installs.

**Architecture:** Commander-based CLI. Registry layer is pluggable (default: `https://cdn.clawforge.dev`, overridable via `--registry`). Installers dispatch per-kind. Manifest lives at `<scope>/.clawforge/manifest.json`.

**Spec reference:** §5 (CLI surface + UX + manifest format), §4.6 (conflict resolution).

|---|---|
| `global` (`~/.claude`) | skill, agent |
| `project` (`./.claude`) | cmd, preset |
| `--scope` flag overrides for any kind | hook, mcp — user must pick |

### Task 8: File-based installer (skill/agent/cmd)

Files: `src/installers/files.ts`, `tests/installers/files.test.ts`.

Algorithm:
1. For each `entry.files[]`:
   - Expand `target` tokens (`{{CLAUDE_DIR}}`, `{{name}}`)
   - Resolve absolute path
   - If missing → copy, record
   - If exists and identical → skip
   - If exists and differs → prompt (unless `--force` → overwrite)
   - If `--dry-run` → record intended write, do not touch disk

Tests (tmpdir-based):
- Clean install writes file
- Second install (same content) skips
- Differing content with `force:true` overwrites
- Dry-run records nothing on disk

**Commit:** `feat(cli): add file-based installer (skill/agent/cmd)`

### Task 9: Merge-based installer (hook/mcp)

Files: `src/installers/merge.ts`, `tests/installers/merge.test.ts`.

Algorithm:
1. Load target JSON (`<claudeDir>/settings.json`), default `{}` if missing
2. Get current value at `mergePath`
3. Compute new value:
   - `strategy: "append"` + array current → `[...current, snippet]`
   - `strategy: "append"` + absent → `[snippet]`
   - `strategy: "replace"` + absent → snippet
   - `strategy: "replace"` + present + force → snippet
   - `strategy: "replace"` + present + no force → prompt
4. Write, record `{ target, path, before, after }`

Tests: append into empty, append into existing array, replace prompts on conflict, dry-run.

**Commit:** `feat(cli): add merge-based installer (hook/mcp)`
